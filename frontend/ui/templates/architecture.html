2 · Interactive Compliance Assistant LangGraph Lifecycle (sample-rag-chatbot/rag_agent/graph.py)

Real-time state machine powering the Gradio chat interface: isolated per-conversation threads (chat-<conv_id>), SQLite turn persistence (db/chat_history.db), dynamic query rewriting, parallel Send routing, context compression, and grounded streaming synthesis.
